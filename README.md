# 📊 Finance Bank Loan Analysis

## 🚀 Objective
Analyzed a bank loan dataset to compute critical lending KPIs and visualize portfolio health and seasonality trends.

## 🛠 Technical Execution
* **Language:** Python
* **Libraries:** Pandas, NumPy (Data Manipulation), Matplotlib, Seaborn (Visualization)
* **Environment:** Jupyter Notebook

## 📈 Key Performance Indicators (KPIs)
* **Total Loan Applications:** 38,576 (MTD: 4,314)
* **Total Funded Amount:** $435.76M
* **Average Interest Rate:** 12.05%
* **Good vs. Bad Loans:** 86.18% Good | 13.82% Bad

## 💡 Business Impact
* Visualized regional lending distribution and loan term preferences using Seaborn area and bar charts.
* Assessed employment length correlation with loan approval rates to optimize risk modeling.
